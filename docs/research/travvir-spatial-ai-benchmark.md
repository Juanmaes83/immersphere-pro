# Travvir Spatial AI Benchmark

## Resumen ejecutivo

Travvir es el benchmark mas relevante para captura smartphone + spatial AI + SDK mobile + iframe enterprise. Su ventaja esta en convertir un telefono en herramienta de captura 360/3D y ofrecer un flujo enterprise integrable. Legalmente, su SDK es propietario y no debe copiarse, modificarse ni derivarse; si interesa, toca partnership/licencia. Lo mas valioso para Immersphere Pro es adaptar el patron de producto: captura -> sesion -> procesamiento -> embed -> analytics -> CRM.

## Que es

Plataforma/app de virtual tours con captura AI desde smartphone, productos de spatial media/replica/layouts, SDK Android/iOS, iframe, pricing pay-as-you-go y enfoque enterprise/partners.

## Valor para Immersphere Pro

- Benchmark de captura: Immersphere tiene visor/CRM/analytics, pero no app propia de captura.
- Benchmark de packaging enterprise: SDK, iframe, analytics, white-label y capture services como extras.
- Benchmark comercial: Travvir vende "Spatial AI", no "tour 360".

## Riesgos

- SDK propietario: no copiar codigo, no derivar, no reverse engineering.
- Documentacion publica contiene fragmentos de API, pero no implica licencia open source.
- Cualquier integracion real exige credenciales/contrato.
- Si se presenta Travvir como partner, confirmar condiciones, territorios, white-label y privacidad.

## Licencia

La documentacion SDK indica copyright Travvir, informacion propietaria y licencia limitada, no exclusiva, no transferible y no sublicenciable. Tambien prohibe reverse engineering, derivar, modificar, distribuir o usar fuera de lo permitido. Clasificacion: C. PARTNERSHIP / LICENCIA para SDK; B. ADAPTABLE para ideas de flujo.

## Que podemos copiar
